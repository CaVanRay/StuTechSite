# Development Guidelines

## This project is intended to be developed collaboratively. Contributors should follow these guidelines:

- Keep HTML, CSS, JavaScript, and PowerShell functionality separated.

- Make changes in feature branches rather than directly modifying the main branch.

- Submit changes through pull requests for review.

- Test changes locally before submitting a pull request.

- Avoid committing generated files, temporary files, or unrelated changes unless they are required by the project.

- Update documentation when introducing new functionality or changing existing workflows.
